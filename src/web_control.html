What do Boot and Insert do?

Boot restarts the Apple from that disk. Save your current work first. The badge remembers it for next time.

Insert in Drive 1 swaps disks while the application keeps running—use it when a game asks for its next disk. Insert in Drive 2 is useful for a data disk. Inserting never formats or erases it.

Some disks contain files but cannot start the Apple by themselves. Boot their DOS/ProDOS or application disk first, then insert the data disk. Adding a disk does not guarantee that its software supports this emulated Apple IIe.

Create an empty data disk

Make a new, blank floppy for your documents or programs. Your Apple application must initialize it before use. This file contains no DOS or other software and cannot boot.

For VisiCalc, insert a new disk named VisiCalc Data.dsk in Drive 2, then use /SI and choose Drive 2. In AppleWorks, insert AppleWorks Data.po in Drive 2, then use Other Activities → Format a disk. Formatting erases the selected disk; select only the new blank one.

Bring your own BASIC source

A .bas text file is a program listing, rather than a floppy image. Open it in the editor, review it, then choose “Enter this program” when BASIC is ready.

You can write and run BASIC without a disk. To use SAVE and LOAD, boot a DOS disk you supply first. The editor also accepts pasted code.

What makes this the real Apple II experience?

The badge runs Apple II software and its original interfaces. VisiCalc uses slash commands, AppleWorks has menus and Open Apple shortcuts, and BASIC programs expose their numbered source lines. The guide explains the controls; the Apple does the work.

These journeys use separate VisiCalc, AppleWorks 2.0, DOS and Oregon Trail disks. Supply your own disk images; they are not included with the firmware. Data disks keep your documents separate from applications. Use a writable DOS disk named Workshop.dsk for your programming workspace.

People also made banners with The Print Shop and used modems to visit bulletin boards. Those need printer or modem support that this badge does not yet provide. Graphics are visible on the physical badge; the browser mirrors text in 40 or 80 columns.

Use the badge without a keyboard
After saving an Applesoft program on your DOS 3.3 disk, return to the empty ] prompt. Press HOME → Saved programs, choose its name, then Run program or Load without running. Up/down choose, A goes back, and B or C selects. Loading replaces the program in memory; save your changes first.
The HOME menu also runs the program already in memory, sends Control-C to stop BASIC, and opens Choose a disk for games and applications. Choose Web control on the HOME screen and press B or C to toggle it. The saved-program list uses drive 1 and currently supports DOS 3.3 Applesoft files.

Small dictionary, in plain English
Prompt: ]
The Apple is waiting for a BASIC command. You don’t type the ] yourself.
BASIC
The programming language built into the Apple. It also works as a calculator.
Program
A set of instructions. In BASIC, the numbered lines are the instructions and RUN starts them.
Memory vs. disk
Memory is your working copy; NEW or power-off clears it. SAVE puts a copy on disk. LOAD brings it back.
DOS
The disk software that understands CATALOG, SAVE and LOAD. It is separate from an application’s own menus.
Boot
Start the computer from a disk. Some disks go straight into a game instead of BASIC.


Local control · HOME → Web control → B or C toggles the web page on the badge. It starts off after a badge reset. USB debugging is still available. Wait for disk activity to finish before unplugging.
