What about VisiCalc, AppleWorks, and other classics?

VisiCalc turned the Apple II into a spreadsheet machine. AppleWorks combined word processing, spreadsheets, and a database. They use their own disks and commands; typing their names into BASIC does not install them.

This badge’s current collection includes DOS 3.3 and an Oregon Trail disk. VisiCalc and AppleWorks are not installed, so they aren’t launch buttons here. The lessons below use what is actually available.

Small dictionary, in plain English
Prompt: ]
The Apple is waiting for a BASIC command. You don’t type the ] yourself.
BASIC
The programming language built into the Apple. It also works as a calculator.
Program
A set of instructions. In BASIC, the numbered lines are the instructions and RUN starts them.
Memory vs. disk
Memory is your working copy; NEW or power-off clears it. SAVE puts a copy on disk. LOAD brings it back.
DOS
The disk software that understands CATALOG, SAVE and LOAD. It is separate from an application’s own menus.
Boot
Start the computer from a disk. Some disks go straight into a game instead of BASIC.


Local control · HOME → C toggles the web page on the badge. It starts off after a badge reset. USB debugging is still available. Wait for disk activity to finish before unplugging.
