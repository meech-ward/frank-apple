First time here?

The Apple II is a personal computer you command by typing. It is great for learning to program, making colourful graphics, and exploring old games.

The ] prompt means BASIC is ready. BASIC is the language built into the Apple. DOS adds disk commands such as SAVE and LOAD.

1 · Use it as a calculator

PRINT asks the Apple to display an answer. Try PRINT 2+2, then change the numbers in the command box.

2 · Give it a few instructions

Without a line number, a command runs immediately. With a number, it becomes part of a program. Our example prints five squares.

Then RUN follows those numbered lines in order. LIST shows what you wrote.

3 · Keep what you made

SAVE MY FIRST writes the current program to disk. LOAD MY FIRST brings it back; RUN MY FIRST loads and runs it.

SAVE updates an existing file with that name. Wait for the badge’s disk indicator to go off before powering down.

4 · Explore the disk

CATALOG lists the files. If the listing pauses, press Return. The DOS disk has a colour-demo menu and Brian’s Theme animation.

For the colour demos, send 3 to choose Kaleidoscope. Brian’s Theme starts with Return. Watch the badge for the graphics.

A useful first project

Write a trip-cost calculator. BASIC asks for distance, fuel use, price, and people sharing. Send each answer from the command box.

Press RUN afterwards. Use LIST to inspect it, change a numbered line to edit it, and save it as TRIP COST.

For an original disk application, try RUN PHONE LIST. It has its own prompts and menus; choose 7 to exit normally before writing another program.

Think like an Apple programmer

The routine is: write a few lines, RUN, fix a line, RUN again, SAVE. Entering an existing line number replaces that line; entering just its number deletes it.

You can make calculators, small databases, graphics and games. Later we can explore the built-in machine-code monitor and 6502 assembly.

When you get stuck

Press Stop, then “Restore text screen.” A syntax error usually means a typo; nothing is broken. NEW clears the program in memory. It does not erase saved files.

This page controls whatever is running. If a program asks a question, type your reply instead of a BASIC command.

Web control is for your trusted home network. Turn it off with HOME → C on the badge’s first disk-menu screen. It also turns off after a restart. USB debugging stays available.
